# Expenses — учёт расходов (Android + Telegram-бот)

Приложение для учёта личных расходов быстрым вводом. Траты можно заносить из двух мест:

- **Android-приложение** (Kotlin + Jetpack Compose);
- **Telegram-бот** — пишешь «кофе 200», трата записывается.

Оба клиента работают с **общими данными**: единый источник правды — база на сервере.

## Устройство репозитория

- `backend/` — серверная часть на **Ktor** (Kotlin). Один сервис = Telegram-бот + HTTP API для приложения. Хранилище — PostgreSQL.
- `androidApp/` — Android-приложение (появится позже).

## Как запустить бэкенд локально

Из папки `backend/`:

```bash
./gradlew run
```

Сервер поднимется на `http://127.0.0.1:8080`. Проверка: открой `http://127.0.0.1:8080/health` — должен вернуться `{"status":"ok"}`.

## Стек

Ktor · PostgreSQL (через Exposed) · kotlinx.serialization · webhook Telegram за nginx на VPS.
