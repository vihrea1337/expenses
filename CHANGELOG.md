# История версий

Формат — по мотивам [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/): сверху новое.
Номера — [семантическое версионирование](https://semver.org/lang/ru/): `МАЖОР.МИНОР.ПАТЧ`.

## [1.2.0] — 2026-10-10

### Добавлено
- Страница установки `/install.html`: APK для Android, ссылка на Telegram-бот, веб-версия.
- Страницы «Конфиденциальность» (`/privacy.html`) и «Условия использования» (`/terms.html`);
  ссылки на них — в подвале веб-приложения и в `/help` бота.
- `SECURITY.md`, `CHANGELOG.md`, `LICENSE`.
- CI: смоук-тест настоящего Docker-образа на Postgres (сквозной сценарий API), артефакты
  (APK, jar, отчёты тестов); Deploy по кнопке через SSH (нужны секреты репозитория).

### Изменено
- Переезд на новый сервер (общий с другим проектом): Docker-стек Postgres + Ktor + Caddy,
  HTTPS на порту **34443** (`https://vihreaexpenses.duckdns.org:34443`). Android-приложение
  собрано с новым адресом — старые сборки к серверу не подключатся.
- Новый ключ Groq — ИИ-категоризация снова работает.
- База на новом сервере создана с нуля.

## [1.1.2] — 2026-09-16

### Исправлено
- CI: сборка Android (принятие лицензий SDK). Релиз по тегу автоматически прикладывает APK.

## [1.1.1] — 2026-09-15

### Добавлено
- Теги трат с фильтрацией; периодическая чистка «надгробий» (окончательное удаление через 90 дней).
- Android офлайн-first: локальный кэш на Room, очередь добавления/правки/удаления без сети.
- Синхронизация по дельте (`/api/expenses/changes`), мягкое удаление, идемпотентность (UUID на клиенте).
- Общий модуль `shared/` с моделями API для бэкенда и Android.

### Изменено
- Переезд на сервер `130.49.176.80` со своим nginx + certbot.

## [1.1.0] — 2026-07-19

### Добавлено
- Мультипользовательские аккаунты: токен = аккаунт, каждый видит только свои траты;
  команды бота `/token` и `/link`.
- График трат по времени, экспорт в CSV, заметки к тратам, меню команд бота.
- Интеграционные тесты репозиториев (H2) и тест CSV-экспорта.

## [1.0.0] — 2026-07-18

Первая версия: Android-приложение, Telegram-бот и веб-страница к одному Ktor-бэкенду на PostgreSQL.
Быстрый ввод («кофе 200»), аналитика по категориям, месячный бюджет, ИИ-категоризация (Groq),
авторизация по токену, тесты и CI (GitHub Actions).
