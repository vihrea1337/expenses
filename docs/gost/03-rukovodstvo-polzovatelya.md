# Руководство пользователя

## автоматизированной системы учёта личных расходов «Expenses»

Разработано по структуре ГОСТ 19.505-79 «Руководство оператора».

---

## 1. Назначение программы

Система предназначена для быстрой фиксации личных трат и последующего анализа
расходов (по категориям, по времени, относительно месячного бюджета). Ввод доступен
тремя равноправными способами: мобильное приложение, Telegram-бот, веб-страница —
данные, введённые любым из них, немедленно видны в остальных.

## 2. Условия выполнения программы

- **Для мобильного клиента:** устройство на Android 8.0 или новее, подключение к
  интернету.
- **Для Telegram-бота:** установленный клиент Telegram (мобильный или настольный).
- **Для веб-клиента:** любой современный браузер.
- Во всех случаях требуется действующий аккаунт в системе (см. раздел 3.1).

## 3. Выполнение программы

### 3.1. Получение доступа (регистрация и вход)

**Через приложение или веб-страницу:** при первом запуске — экран входа с двумя
вариантами: **войти по токену** (если аккаунт уже есть) или **создать новый аккаунт**
(указав отображаемое имя — сервер выдаст токен, его нужно сохранить: это единственный
способ войти повторно).

**Через Telegram-бота:** команда `/token` — бот создаёт новый аккаунт и присылает
токен. Команда `/link <токен>` — привязать Telegram-аккаунт к уже существующему
аккаунту (например, созданному в приложении), чтобы бот и приложение показывали одни
и те же траты.

### 3.2. Добавление траты

**В боте:** отправить сообщение вида `<описание> <сумма>`, например:
```
кофе 200
такси до дома 350
```
Последнее слово распознаётся как сумма, всё до него — как категория/описание. Бот
подтверждает запись в чате.

**В приложении и на веб-странице:** заполнить форму (сумма, категория, необязательно —
заметка и тег) и нажать «Добавить». Приложение работает и без интернета: трата
сохраняется локально и отправляется на сервер автоматически при восстановлении связи
(индикатор синхронизации показывает несинхронизированные записи).

### 3.3. Просмотр и редактирование трат

Список трат доступен во всех трёх клиентах с фильтром по периоду (сегодня / неделя /
месяц / всё) и по тегу. В приложении и на веб-странице можно отредактировать сумму,
категорию, заметку и тег уже добавленной траты либо удалить её (нажатием на запись).

### 3.4. Аналитика

Веб-страница и приложение показывают:
- **Кольцевую диаграмму** — доля расходов по обобщённым категориям (при наведении —
  подсказка с категорией, суммой и долей);
- **График по времени** — расходы по дням или месяцам за выбранный период;
- **Карточку бюджета** — «потрачено X из Y, осталось Z» (перерасход подсвечивается),
  если задан месячный лимит.

### 3.5. Бюджет

В настройках приложения/веб-страницы можно задать месячный лимит расходов — карточка
аналитики начнёт показывать остаток и предупреждение при превышении.

### 3.6. Автоматическая категоризация

Каждой новой трате сервер в фоне пытается подобрать одну из обобщённых категорий
(еда, транспорт, дом, развлечения, здоровье, одежда, связь, подарки, прочее) на
основе описания — категория появляется в интерфейсе с небольшой задержкой (несколько
секунд) после добавления траты, без каких-либо действий пользователя.

### 3.7. Экспорт данных

Кнопка «Экспорт в CSV» (приложение и веб-страница) выгружает все траты пользователя в
файл-таблицу, который открывается в Excel или Google Таблицах.

## 4. Сообщения оператору

| Ситуация | Сообщение / поведение | Действие пользователя |
|---|---|---|
| Неверный или просроченный токен | Отказ входа | Проверить токен, при потере — создать новый аккаунт |
| Нет соединения с сервером (приложение) | Трата сохраняется локально, помечена как несинхронизированная | Не требуется — синхронизация произойдёт автоматически при восстановлении сети |
| Бот не распознал сумму в сообщении | Бот сообщает об ошибке разбора | Повторить сообщение, убедившись, что оно заканчивается числом |
| Категория не проставилась автоматически | Трата остаётся без обобщённой категории | Не является ошибкой (ИИ-сервис недоступен или не настроен на сервере) — можно задать категорию вручную |
| Превышение месячного бюджета | Индикатор в карточке бюджета подсвечивается | Информационное сообщение, не блокирует добавление трат |
