# CLAUDE.md — точка входа в проект Expenses

Короткая ориентировка для ИИ-агента и разработчика. **Подробности — в документах ниже, они источники правды.**

## Что это
**Expenses** — приложение учёта личных расходов быстрым вводом. Траты заносятся из ДВУХ мест — Android-приложение и Telegram-бот («кофе 200» → запись), оба видят общие данные. Единый источник правды — база на сервере. Портфолио-проект, показывает клиент-серверную архитектуру.

## Язык
Общение в чате, комментарии в коде и документация — **на русском**. Объяснять как junior-разработчику: без риторики, расшифровывая термины и аббревиатуры.

## Формат работы (важно!)
**Весь код пишет Claude** (решение пользователя от 2026-07-18): пользователь — junior, изучает готовый результат и тестирует после деплоя. Поэтому:
- **Код Claude пишет сам**, но с подробными русскими комментариями «как для junior» — чтобы пользователь мог разобраться постфактум.
- **На VPS у Claude доступа нет.** Для серверных шагов Claude даёт точные команды/конфиги, а выполняет их на сервере **пользователь сам** (заходит по SSH).
- Коммиты — **без** трейлера `Co-Authored-By: Claude` (чистое авторство для портфолио).
- _(Историческая справка: до 2026-07-18 был гибрид — логику писал пользователь, Claude делал обвязку и ревью. Так делались ранние срезы.)_

## Бэкенд: команды
Из папки `backend/` (JDK берём из Android Studio):
```powershell
$env:JAVA_HOME='C:\Program Files\Android\Android Studio\jbr'
.\gradlew.bat run          # запустить локально на http://127.0.0.1:8080
.\gradlew.bat build        # собрать и проверить
.\gradlew.bat buildFatJar  # собрать один jar для деплоя: build/libs/expenses-backend-all.jar
```
Проверка живости: `http://127.0.0.1:8080/health` → `{"status":"ok"}`.

## Ключевые факты
- Package: `io.github.vihrea1337.expenses`. GitHub: https://github.com/vihrea1337/expenses (**private**).
- Тулчейн бэкенда: **Kotlin 2.1.0**, **Ktor 3.0.3**, **Gradle 8.14.3** (wrapper), **JDK 21** (JBR Android Studio).
- Хранилище (планируется): **PostgreSQL** через **Exposed**; JSON — kotlinx.serialization.

## Текущее состояние (кратко)
**v1.1 готова и развёрнута.** Три клиента (Android, Telegram-бот, веб-страница) к одному Ktor-бэкенду на VPS с PostgreSQL. Реализовано: быстрый ввод, REST API, **мультипользовательские аккаунты** (токен = аккаунт, изоляция; бот `/token`·`/link`), авторизация bearer-токеном, аналитика по категориям (donut) и **график по времени**, месячный бюджет, ИИ-категоризация трат (Groq), **экспорт CSV**, бот-меню (`setMyCommands`), тесты+CI (парсер, CSV, репозитории на H2). Детали — в `README.md` и `docs/`.
